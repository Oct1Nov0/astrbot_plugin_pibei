# 谷圈云黑插件

一个用于谷圈的避雷（云黑）记录插件，基于 AstrBot + SQLite。支持录入风险QQ号、查询、撤销，记录永久保留不删除。

## 功能

查询指令（所有人可用）：

- `/查 QQ号` 查询某个QQ的有效避雷记录
- `/详情 案件号` 查看某条案件完整信息
- `/分类列表` 查看可用的风险分类
- `/避雷帮助` 查看全部指令

管理员指令（仅配置的管理员QQ可用）：

- `/录入 QQ号 分类 金额 事件经过` 录入一条避雷记录，录入即生效
- `/撤销 案件号` 撤销一条记录（保留历史，状态改为已撤销）
- `/添加分类 名称` 新增一个风险分类

## 示例

录入：

```
/录入 123456 团长骗钱 1200 收了钱不发货，已拉黑
```

查询：

```
/查 123456
```

## 配置

管理员QQ号在 `main.py` 顶部的 `ADMIN_QQS` 列表里配置。

## 数据存储

记录存放在插件目录下的 `data/pibei.db`（SQLite）。首次运行自动建表并初始化默认分类。

## 默认分类

团长骗钱、排谷后跑单、故意出盗版谷、伪造凭证、代购骗钱、其他。可用 `/添加分类` 扩展。
