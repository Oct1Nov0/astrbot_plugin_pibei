# 谷圈云黑库插件

基于 AstrBot + SQLite 的谷圈云黑记录插件。支持录入风险QQ号、查询、撤销，记录永久保留。

## 功能

查询指令（所有人可用）：

- `/查 QQ号` 查询某个QQ的有效云黑记录
- `/详情 案件号` 查看某条案件完整信息
- `/分类列表` 查看可用的风险分类
- `/云黑帮助` 查看全部指令

管理员指令（仅配置的管理员QQ可用）：

- `/录入 QQ号 分类 金额 事件经过` 录入一条云黑记录，录入即生效
- `/撤销 案件号` 撤销一条记录（保留历史，状态改为已撤销）
- `/添加分类 名称` 新增一个风险分类

## 安装

在 AstrBot WebUI 的插件管理页面，通过 GitHub 地址安装：

```
https://github.com/Oct1Nov0/astrbot_plugin_pibei
```

## 配置

安装后在 AstrBot WebUI 的插件配置页面设置：

- **管理员QQ号**：填入管理员的QQ号，多个用英文逗号隔开
- **白名单群号**：填入允许使用云黑库的群号，多个用英文逗号隔开。留空表示所有群都可用

配置修改后保存即可生效，无需重启。

## 示例

```
/录入 123456 团长骗钱 1200 收了钱不发货，已拉黑
/查 123456
/撤销 C202606010001
```

## 数据存储

记录存放在插件目录下的 `data/pibei.db`（SQLite）。首次运行自动建表并初始化默认分类。

## 默认分类

团长骗钱、排谷后跑单、故意出盗版谷、伪造凭证、代购骗钱、其他。可用 `/添加分类` 扩展。
